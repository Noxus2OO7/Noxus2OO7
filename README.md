## 🚀 Proyecto destacado

###  EcoRoute Logistics

Proyecto académico de desarrollo de una solución SaaS enfocada en la optimización de rutas de entrega para pequeñas flotas de vehículos.

**Objetivos principales:**
- Optimización de rutas de entrega.
- Gestión de vehículos, conductores y pedidos.
- Visualización de información logística.
- Cálculo de emisiones de CO₂ ahorradas.

**Tecnologías del proyecto:**

React · Node.js · Express · PostgreSQL · PostGIS · AWS

[🔗 Visitar repositorio de EcoRoute Logistics](https://github.com/EcoRoute-Logistics/EcoRoute-Logistics)
